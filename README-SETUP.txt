TECH-NORTH MOBILE APP — V5

This package keeps the existing Tech-North inspection report app and adds a clearer phone installation and export-to-device flow. It is a Progressive Web App (PWA), not an APK and not an App Store / Google Play app.

UPLOAD
1. Extract this ZIP.
2. Upload ALL files inside the mpi-main folder to the same folder on your HTTPS website. Keep the filenames and folder structure unchanged.
3. The website must use HTTPS. Do not open index.html directly from Downloads or a USB drive.
4. Open the website online once on each phone.

INSTALL ON HUAWEI / ANDROID
1. Open the HTTPS website in a browser that supports PWA installation (Chrome is the recommended fallback if the current browser does not support it).
2. Tap Install App. If the browser provides its installation prompt, accept Install.
3. If the browser does not provide a prompt, the app explains where to find Install app / Add to Home screen in the browser menu.

INSTALL ON IPHONE
1. Open the HTTPS website in Safari.
2. Tap Install App. The app displays Apple's required steps.
3. In Safari, tap Share, scroll and choose Add to Home Screen, then tap Add.
Apple does not allow a website to launch the final Add to Home Screen confirmation automatically.

SAVE AND EXPORT FILES
- When a report, backup, PDF, Excel or Word file is generated, a save panel appears.
- Tap Save to phone. Browsers supporting the native file picker let you choose the destination.
- On iPhone, the Save to phone action opens the iOS share sheet when file sharing is supported; choose Save to Files and select On My iPhone or iCloud Drive.
- If the native picker/share route is unavailable, tap Download file. Android browsers generally place the file in Downloads or ask for a location.
- Share file is a separate option for sending the export to a supported app.

IMPORTANT DATA NOTE
Reports and examiner profiles are stored locally in each browser/app's site storage. They do not automatically sync between phones. Use Full backup regularly and transfer the backup file when moving data to another device. Keep the app's website data intact to avoid losing locally saved reports.

TESTING NOTE
The package can be checked for ZIP integrity and JavaScript syntax before upload, but installation and file saving must still be tested on the actual Huawei and iPhone because browser support and website hosting configuration vary.
